## Scaling Prometheus with the help of the operator

When using Prometheus to monitor applications deployed in Kubernetes clusters, we often face challenges due to the scale and dynamic nature of the workloads. In this talk, we will see how the Prometheus operator can simplify this burden with techniques such as target sharding and autoscaling. We will also learn how to limit cross availability-zone traffic and reduce networking costs. Finally we will show how to enable a global query and rule evaluation system by leveraging Thanos.
